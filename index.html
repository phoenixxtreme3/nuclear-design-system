Introduction

What is Nuclear?

Nuclear is LoveLocal's design system — the shared colors, type, spacing and components behind the B2C app. This release covers the base foundation tokens, the full Nuclear v2.0 icon library, and the Navigation surfaces (header, bottom tab bar and category filter), pulled directly from Figma and documented the way you'd expect from a production design system: one topic per page, with an introduction, specs, and usage guidance before the next topic.

How this site is organized

  • Foundations — the raw tokens: color, typography, spacing/radius/size, and the icon library. Everything else is built from these.
  • Components — assembled UI built from the foundations, starting with Navigation Header (fully built out in code), Bottom Tab Bar and Category Filter (documented from their Figma reference).

Governance

  • Source of truth — Figma is upstream. Changes start there, get design sign-off, then sync into this repo.
  • Versioning — semver. Patch = corrections, no visible change. Minor = new tokens/components, additive. Major = renamed/removed tokens or breaking changes.
  • Contributing — propose in Figma first, then open a PR here updating source and docs together. @design-systems is a required reviewer.
  • Deprecation — marked one minor version before removal, with its replacement noted, removed at the next major version.
