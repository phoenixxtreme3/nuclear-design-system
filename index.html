Navigation Header

The app's top bar on the Home screen — greeting, location, coin balance and search, in light and dark-background variants, built entirely from the tokens above. Markup, CSS and accessibility notes live in the repo.

Using these tokens

Link tokens.css once at the app level, then reference the custom properties it defines — no build step required.

<link rel="stylesheet" href="/tokens.css" />

.my-button {
  background: var(--brand-primary);
  color: var(--content-on-color);
  font-family: var(--font-sans);
}
