Components

Category Filter

A horizontally-scrolling chip carousel used on the Shop screen to filter by category, paired with the shop-type icon set (chicken, fish, fruit, grocery, meat-and-fish, veg — see Icons) rendered as small animated glyphs above each chip's label.

States

Captured directly from Nuclear v2.0's Navigation page in Figma. This component doesn't yet have its own HTML/CSS build-out — these are the reference states to build against.

Category filter — carousel
Chip row, selected/unselected
Shop-type animated icons
All shop-type icon variants used by the filter

Usage guidelines

Do keep one chip selected at a time; let the row scroll rather than wrapping chips onto a second line.

Don't mix the animated shop-type glyphs with static icons in the same row — pick one icon style per surface.
